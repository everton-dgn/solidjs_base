# solid-base-runtime

For localized links, supply a base when resolving relative page URLs with
resolveLocalizedHref. See [locale support](../../docs/i18n.md).

For SSR environment validation, spread serverEnv into the server schema and add
application-specific keys there. See [environment values](../../docs/env.md).
